# Actividad 2: JavaScript y Paradigmas de Programación

Repositorio con los ejemplos desarrollados en clase sobre los fundamentos de JavaScript, programación funcional y programación orientada a objetos (POO).

## Estructura del Proyecto

- `app.js`: Conceptos básicos de JavaScript (variables, tipos de datos, arreglos, funciones y prototipos).
- `cal.js`: Programación funcional aplicada a una calculadora (callbacks, promesas y async/await).
- `poo.js`: Programación Orientada a Objetos mediante una jerarquía de animales (clases, herencia, getters/setters y polimorfismo).

## Requisitos

- Node.js instalado (v14 o superior).

## Instrucciones de Ejecución

Para correr cada script en la terminal, ejecuta:

```bash
node app.js
node cal.js
node poo.js
